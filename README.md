# Pathik Ahmed

**Data Science · Machine Learning · Reliable AI · Research Software**

Master of Data Science student at Macquarie University, Sydney. My work spans graph machine learning, anomaly detection, time-series forecasting, medical computer vision and reliability-focused evaluation.

I am particularly interested in building machine-learning systems that remain useful under real-world conditions such as distribution shift, class imbalance, noisy data and uncertain evidence, and in translating research workflows into practical, interactive tools.

## Research

- **Graph-based fraud detection**: reproducible evaluation under class imbalance, heterophily and camouflage.
- **Time-series forecasting**: reproduction and generalisation of LTSF-Linear/DLinear under changing data conditions.
- **Medical computer vision**: first-authored IEEE work on fetal head-circumference estimation using CNN-based regression and segmentation.
- **Optimisation**: co-authored IEEE work on constrained particle-swarm optimisation.
